Esta vista previa no ejecuta la app. En iPhone, la vista previa de Archivos, Mail o WhatsApp no corre JavaScript, y Safari no abre archivos .html guardados en el teléfono.

Cómo abrirla:

  1. iPhone (recomendado): publica este archivo como página (Vercel, GitHub Pages u otro) y abre el enlace en Safari. Solo se publica la app: las fotos quedan guardadas en el teléfono.
  2. iPhone 100 % local: app gratuita iSH → copia el archivo a Archivos › iSH › root con el nombre index.html → en iSH escribe apk add python3 (una vez) y python3 -m http.server → en Safari abre localhost:8000.
  3. Android, Windows o Mac: abre el archivo con Chrome, Edge o Safari (Mac).

Ayuda

  • Foto rápida: botón de cámara a la derecha de cada ítem.
  • Bucle + RCD: cada circuito lleva 2 fotos, Bucle y Dif. Tocar otra vez una de ellas repite la foto (reemplaza la anterior).
  • Toca el ítem para ver sus fotos, usar la Galería, escribir una nota o marcar «No aplica».
  • Las fotos quedan en este teléfono; no se suben a internet. Siguen ahí aunque cierres la pestaña.
  • Exportar ZIP → Compartir → Guardar en Archivos, AirDrop, Mail o WhatsApp (va como documento y no se comprime). Fotos originales, sin pérdida de calidad.
  • El ZIP trae resumen.csv (Excel) y datos_informe.json para armar el informe Word de 2C.
  • iPhone: usa Safari, abriendo la checklist desde su enlace https. En el visor de otras apps la cámara no entrega la foto.
  • Respaldo: exporta el ZIP al terminar cada jornada. Si se borran los datos de Safari, se pierden las fotos.
  • Usa siempre el mismo acceso (pestaña de Safari o ícono en la pantalla de inicio): cada uno guarda sus fotos por separado.
  • Varios ítems a la vez: separa con comas o usa rango, ej.: CTO 1..12.
